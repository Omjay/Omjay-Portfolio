How six hours became thirty minutes

Four changes I made at Azimuth GRC, in the order I made them, while the data grew from 20M records past 500M+.

  1. Automated the whole run

    Replaced a manual 6-hour process with one Azure Data Factory and Databricks pipeline, from raw-data validation to the Tableau refresh.

    Azure Data Factory, Databricks

  2. Loaded only what changed

    Incremental Delta Lake loads and merges, so each run skips the data it has already processed.

    Delta Lake, PySpark

  3. Fixed the skew as data grew

    Past 500M+ records one oversized partition held up every run; Liquid Clustering and compaction spread the load evenly.

    Liquid Clustering, Delta

  4. Remodeled and right-sized

    A Gold-layer star schema made queries 65% faster; job clusters, autoscaling and Photon cut DBU spend 25%.

    Star schema, Photon
