Legacy server to Databricks Workflows

Ubuntu, Databricks, Delta Lake

  • Migrated 40+ production Python scripts off a legacy Ubuntu server onto Databricks Workflows.
  • Resolved the data skew in the thrice-daily flagship pipeline and moved it to job compute clusters: about 30 minutes a run instead of 1 h 50 m, and about 70% fewer daily compute hours.
  • Orchestration, retries and alerting replaced cron jobs and manual restarts.

Branch-based dev environments on Snowflake

Snowflake, Azure DevOps, Git

  • For a client platform, creating a feature branch from main triggers an Azure DevOps pipeline that zero-copy clones the full production database for that branch.
  • Every clone gets a unique uppercase name, DATABASE_BRANCH_YYYYMMDD, so each environment traces back to its branch and the day it was cut.
  • 15+ engineers test changes against real production data as of branch creation, without touching production or duplicating storage.
  • A month-end job drops clones of feature branches with no push for a month; main, prod and non-feature branches are never dropped.
