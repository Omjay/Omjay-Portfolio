About

Data engineering built around measurable outcomes.

I am Om Jay Mishra, an Azure-focused Data Engineer based in Chennai, India. I design, build and improve data platforms that make large datasets faster to process, easier to govern and more dependable for analytics teams.

Professional focus

My core work spans Azure Databricks, PySpark, Delta Lake, Azure Data Factory, SQL and Python. I have worked across ingestion, incremental processing, medallion architecture, Gold-layer modelling, orchestration, data-quality controls, Unity Catalog, CI/CD and production support. I care about the complete delivery path: source reliability, transformation correctness, efficient compute, discoverable data and useful downstream reporting.

Evidence from my work

At Azimuth GRC, I helped build and optimize a compliance-data Lakehouse, including a 500M+ record workflow reduced from six hours to thirty minutes, a Gold-layer Star Schema that improved query performance by 65%, Unity Catalog governance, and cluster changes that reduced Databricks DBU use by 25%. At ExaQube Technologies, my work includes moving legacy production processes to Databricks Workflows and Delta Lake. Earlier at PlanetSpark, I automated reporting and engagement analysis for more than 10,000 users.
