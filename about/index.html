About

Data engineering built around measurable outcomes.

I am Om Jay Mishra, an Azure-focused Data Engineer based in Chennai, India. I design, build and improve data platforms that make large datasets faster to process, easier to govern and more dependable for analytics teams.

Professional focus

My core work spans Azure Databricks, Snowflake, PySpark, Delta Lake, Azure Data Factory, SQL and Python. I have worked across ingestion, incremental processing, medallion architecture, Gold-layer modelling, orchestration, data-quality controls, Unity Catalog, CI/CD and production support. I care about the complete delivery path: source reliability, transformation correctness, efficient compute, discoverable data and useful downstream reporting.

Evidence from my work

At Azimuth GRC I built the Azure Data Factory and Databricks pipeline that replaced a manual six-hour process with a thirty-minute run. It started at 20M records, still ran in about thirty minutes past 500M+, and the data has since grown to about 4 billion. Around it I led the move to a Lakehouse, designed a Gold-layer star schema that made queries 65% faster, set up Unity Catalog governance, and cut Databricks DBU use by 25%. At ExaQube Technologies I am moving legacy production processes onto Databricks Workflows and Delta Lake, and for a client I automated branch-based Snowflake dev environments that zero-copy clone the production database for each feature branch. Earlier, at PlanetSpark, I automated reporting and engagement analysis for more than 10,000 students.
