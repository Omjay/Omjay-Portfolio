# Om Jay Mishra - Data Engineer

Om Jay Mishra is an Azure-focused Data Engineer in Chennai, India. He builds governed Lakehouse platforms with Azure Databricks, Snowflake, PySpark, Delta Lake, Azure Data Factory, SQL and Python. His toolkit also includes KQL for querying and dbt for data modeling.

Available for freelance and consulting work: slow or costly Databricks pipelines, manual processes that should be pipelines, Lakehouse migrations, and Snowflake branch-based dev environments.

## Selected impact

- Built the Azure Data Factory and Databricks pipeline that turned a manual six-hour process into a thirty-minute run at 20M records, and kept it near thirty minutes past 500M+ records with incremental Delta loads, Liquid Clustering for partition skew, and job-cluster tuning. Every Tuesday the run checked about 150,000 records against 85 compliance tests (about 12.75 million results), into a results table that grew to about 4 billion rows.
- Improved Gold-layer query performance by 65% across more than 50M records using a Star Schema.
- Reduced Databricks DBU consumption by 25% using job clusters, autoscaling and Photon.
- Eliminated more than 270 hours of manual work through ADF and Databricks automation.
- Implemented Unity Catalog from scratch for centralized governance, fine-grained access controls and audit tracking.

## Experience

- **ExaQube Technologies:** Data Engineer, the only data engineer at a 10-person startup, modernizing production workloads with Databricks Workflows, Delta Lake, Docker and Python; cut a thrice-daily pipeline from ~1h 50m to ~30 min per run and daily compute hours by ~70%. For a client, automated branch-based Snowflake dev environments: Azure DevOps zero-copy clones the production database per feature branch, and a month-end job drops stale clones (15+ engineers).
- **Azimuth GRC:** Data Engineer who led a two-person data team at a 30-person startup, building and optimizing an Azure Databricks compliance-data Lakehouse; also containerized a VPN-dependent pipeline with Docker on Azure.
- **PlanetSpark:** Data Analytics Engineer, junior member of a two-person data team at a startup of about 40, automating reporting for more than 10,000 student records, cutting manual reporting cycles by 40%, and building engagement analysis.
