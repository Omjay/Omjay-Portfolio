Representation and protocol boundaries

GitHub Pages serves static files and does not perform request-time content negotiation. Agents should follow the advertised rel="alternate" link or request index.md directly when Markdown is preferred. No MCP endpoint is advertised because this portfolio has no callable product API or safe transactional tools. A future MCP server should be added only with a defined tool surface, security model, supported transport and server-capable hosting.
